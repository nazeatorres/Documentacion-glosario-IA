Glosario Técnico de Arquitectura de Agentes

Documentación Académica Basada en el Taller Colectivo del Diplomado en IA

1. Entidades y Sistemas de Agentes
Agente
Entidad, software o algoritmo impulsado por inteligencia artificial que actúa de forma autónoma siguiendo instrucciones específicas para percibir su entorno, tomar decisiones y ejecutar acciones orientadas a cumplir una meta u objetivo determinado.
Multiagente
Estructura, entorno o equipo integrado por un grupo de varios agentes de Inteligencia Artificial que interactúan, cooperan y trabajan de forma coordinada bajo un mismo marco para lograr una meta común.
Utilidad de un Multiagente
Sirve principalmente para la resolución de problemas de alta complejidad, dividiendo tareas de gran envergadura en partes más pequeñas y especializadas, logrando que los agentes operen simultáneamente de forma más rápida y uniendo varias capacidades analíticas.
2. Interfaces, Herramientas y Simulación
Droid
Framework de orquestación, interfaz técnica o herramienta diseñada para automatizar flujos de trabajo avanzados, ejecutar tareas de programación o controlar operativamente las interacciones de un sistema de agentes (así como robots inteligentes autónomos en entornos físicos).
Fake Bot
Un bot o programa simulado diseñado para interactuar de forma fluida y simular una conversación o comportamiento humano real en canales digitales, pero que no necesariamente cuenta con IA real bajo su arquitectura.
Diferencia entre Claude y Droid
Claude es una Inteligencia Artificial conversacional (LLM) desarrollada por Anthropic enfocada en razonar, explicar y generar contenidos desde la nube. Por el contrario, Droid funciona como el framework técnico, interfaz o robot que se encarga de ejecutar tareas operativas, comandos y automatizaciones específicas dentro del sistema.
3. Control de Versiones e Infraestructura Nube / Local
Repositorio
Espacio de almacenamiento digital estructurado y centralizado enfocado en guardar, organizar y registrar minuciosamente cada cambio y versión de los archivos, códigos y componentes de desarrollo que conforman un proyecto.
GitHub y su Funcionamiento
GitHub es una plataforma web en la nube construida para alojar repositorios digitales de software. Funciona permitiendo a equipos de desarrollo subir código, registrar historiales de modificaciones, coordinar flujos y colaborar conjuntamente en la creación y despliegue de soluciones tecnológicas.
Open Cloud
Estructura e infraestructura de computación en la nube basada en estándares abiertos, diseñada para almacenar, conectar y desplegar servicios o herramientas por internet sin restricciones de proveedores cerrados de software.
Sesión de Uso en Ollama
El lapso temporal, instancia o conversación activa en la cual un usuario ejecuta de forma local y privada un modelo de Inteligencia Artificial directamente en la memoria y procesamiento de su propio computador a través del software Ollama.
4. Capacidades Avanzadas e Interacción
Sistema Predictivo de Agentes
Estructura inteligente donde múltiples agentes analizan variables, modelos y datos históricos para anticipar eventos, resultados futuros o predecir patrones de comportamiento de forma automatizada.
Capacitaciones con un Agente
Implementación pedagógica que sirve para que un agente experto en IA enseñe, explique, entrene u oriente paso a paso a una persona o instructor sobre una temática corporativa o técnica sin requerir asistencia humana continua.
Skills (Habilidades)
Capacidades específicas, funciones programadas o herramientas externas que se le enseñan, integran o asignan a un agente de Inteligencia Artificial para que logre ejecutar tareas puntuales y resolver problemas de forma efectiva.
